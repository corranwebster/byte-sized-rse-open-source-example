# Example Repository for Byte-Sized RSE: Working with Open Source

This repository is intended to be used as an example open-source project that attendees of a [Byte-Sized RSE: Working with Open Source](https://southampton-rsg-training.github.io/byte-sized-rse-open-source/index.html) session can work with.

This repository should not be used itself, rather the instructor must create a new repository using this repository as the template, and students should work against the instructor's copy.

This example uses the folk story [Stone Soup](https://en.wikipedia.org/wiki/Stone_Soup) as an allegory for the way that open source software works.
